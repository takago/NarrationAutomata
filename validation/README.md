# ナレーション品質検査

品質検査タブでは，ルールによる全体検査，LLMによるスライド別検査，LLMによる全体検査を任意に複数選択し，「検査を開始」で順次実行します．開始時に以前の検査結果は全件置き換えられます．

検査中はサイドバーとタブ内の進捗を更新し，問題が見つかった順にスライド単位で折りたたみリストへ表示します．同じスライドへの複数の指摘は一つにまとめます．検査中は閲覧のみです．中断時はその時点の検査結果を表示します．

検査終了後は，スライドごとに一つの編集欄を開けます．「再生成」は既存のナレーション生成処理から新しい候補を作成し，「自動校正」は編集中の文章と検査指摘をLLMに渡して校正します．いずれも編集欄にだけ反映されます．「元に戻す」は検査時の文章に戻します．「保存」を押した場合にだけ原稿ファイルを更新して下流生成物を無効化し，そのスライドを問題一覧から除外します．

手動モードでは修正履歴や自動承認状態を管理しません．検査結果はプロジェクト内の `validation/results.json` に保存し，LLMの利用統計は既存の `statistics.jsonl` に記録します．

## オートリファイナー（追加）

デフォルトはONで，自動実行は1回限りです．必要に応じて手動で再実行できます．選択した検査を「ルール→LLM個別→LLM全体」の順に実施し，LLM検査で問題を見つけたスライドを自動校正して，妥当な出力だけを原稿へ保存します．修正後のスライドについては下流生成物を無効化します．自動修正した場合は読み取り専用の確認検査を行います．ルールベース検査で見つかった問題は自動再生成せず，最後にまとめて手動修正を求めます．検査エラーと未解決の指摘は手動確認用に残します．

結果画面ではスライドごとに処理段階，検出理由，修正結果および修正前後の差分を確認できます．履歴は `validation/results.json` の `auto_refiner.history` に保存します．以前の履歴は新しい検査開始時に置き換わります．OFFでは従来の手動検査・編集操作を使用します．
